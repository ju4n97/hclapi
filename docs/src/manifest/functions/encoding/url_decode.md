# url_decode

Unescapes a URL percent-encoded string.

## Signature

```hcl
url_decode(str: string) -> string
```

## Parameters

| Parameter | Type     | Required | Description            |
| :-------- | :------- | :------- | :--------------------- |
| `str`     | `string` | yes      | The URL encoded string |

## Return value

Returns the decoded `string`.
