# base64_decode

Decodes a standard Base64 encoded string back into plain text.

## Signature

```hcl
base64_decode(str: string) -> string
```

## Parameters

| Parameter | Type     | Required | Description                 |
| :-------- | :------- | :------- | :-------------------------- |
| `str`     | `string` | yes      | The Base64 string to decode |

## Return value

Returns a decoded plain text `string`.
